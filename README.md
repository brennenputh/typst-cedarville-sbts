# typst-cedarville-sbts

The Cedarville University SBTS Style Guide, implemented in Typst!

> [!WARNING]
> There is no guarantee that this template will produce PDFs exactly matching the style guide. Each paper should be checked before being submitted. 
>
> This template is not officially supported by the university and is liable to break at any time.

This repository currently supports the latest version of Typst (0.15.1 at the time of writing) and the style guide from 2024-2025.

## Usage Steps

> [!NOTE]
> This package depends on the Times New Roman font being installed. If you are using Typst locally, it will work if the font is on your system. 
>
> The font is not installed in the Typst web application due to [issues with licensing](https://github.com/typst/webapp-issues/issues/694). If you are using Typst's web application with this project, you will have to find a free alternative.

1. Download this GitHub repo by cloning or as a zip file.
2. Copy the `template` folder to wherever you want to store your files, and rename the folder to your current project.
3. Change the values in the `main.typ` file to whatever you need for your paper.
4. Begin writing in `main.typ`, and edit like any other Typst document! See the documentation for Typst [here](https://typst.app/docs/tutorial/writing-in-typst/).
